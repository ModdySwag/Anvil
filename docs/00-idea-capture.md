## The idea (one paragraph)
A flagship browser synthesizer in the Pattern Forge family: pro-grade multi-engine sound (acid/bass, wavetable/additive, FM, physical modelling, drums), a groovebox-grade sequencer, performance controls, a studio FX rack, and a community-multi-user layer (profiles, shareable sounds, cloud libraries, factory + community packs) — zero install, instant sound, export-ready, with the flair that makes producers grin. Built on the proven Pattern Forge engine core and the ecosystem rules Moddy already runs (local-first, no credits/metering, open formats, CC0-first content with provenance manifests).

## Working frame (defaults — owner can flip any)
- **Standalone product, shared engine, shared ecosystem.** Not a hidden PF tab: PF is a workstation; this is an instrument. Engine DNA, pack formats and verification culture are shared; the suite index links them.
- **Browser-first, local-first.** Runs from a URL or a single file; no accounts required for full sound use; cloud = convenience layer (T6 phases).
- **v1 identity:** flagship breadth with an acid heart (the tabs' emotional hook) — "producer's synth" positioning: sound quality + sequencer + packs first, community second.
- **Platform targets:** Chrome/Edge/Firefox primary; Safari best-effort (engine task documents the gap); desktop shell (Electron) later per suite plan.
- **Content:** 8–10 factory packs from day one via The Foundry pipeline (own-authored + CC0 bases; engine-witness verification tiers A/B/C).
- **Non-goals for v1:** full DAW/arrangement replacement; hosting external plugins; scorings/video; mobile-native apps; real-time audio collaboration in v1 (assessed in T6, phased P3).
